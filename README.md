# LunarTIles
LunaTiles is a space‑themed image puzzle game that automatically fetches fresh online images, supports 3×3 to 6×6 grids, tracks moves/time/score, and includes a 10‑second countdown + hint overlay. Built with vanilla HTML, CSS, and JS – no backend needed.




## 🎮 How to Play
1. Click **✨ New** – you’ll see the solved image for 10 seconds.
2. Tap a tile to select it, then tap an adjacent tile to swap.
3. Rearrange all tiles to recreate the image.
4. Solve it, and your score will be compared to the best.

## 🛠️ Tech Stack
- HTML5, CSS3 (flexbox, grid, glassmorphism, animations)
- JavaScript (ES6, async/await, Web Audio API)
- localStorage for persistence
- Unsplash & Picsum APIs for images
